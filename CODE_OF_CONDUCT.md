# Code Of Conduct

This project aims to be a practical engineering knowledge tool. Keep discussions technical, specific, and respectful.

## Expected Behavior

- Explain tradeoffs with evidence.
- Assume good intent, but be precise.
- Keep issues and pull requests focused.
- Credit original sources.

## Unacceptable Behavior

- Harassment, insults, or personal attacks
- Spam, astroturfing, or fake source submissions
- Posting secrets or private data
- Misrepresenting generated analysis as original source text

Maintainers may close issues, remove comments, or block users who repeatedly violate these expectations.
