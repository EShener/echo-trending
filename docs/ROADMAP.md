# Roadmap

## Phase 1: Trustworthy Daily Radar

- Keep hourly GitHub Pages publishing stable.
- Maintain 90-day report retention.
- Add source quality checks for malformed dates, empty project lists, and failed image URLs.
- Make the default page scannable while preserving expandable deep dives.

## Phase 2: Better Technical Interpretation

- Improve project clustering: agent tools, infra, data, AI apps, developer productivity.
- Add source confidence and freshness indicators.
- Add cross-day trend deltas: new entrant, repeated signal, cooling project.
- Separate "hype" from "production relevance" in scoring.

## Phase 3: Community Contributions

- Accept source suggestions through issue templates.
- Add labels for `source`, `ui`, `analysis`, `good first issue`, and `roadmap`.
- Publish a weekly changelog issue summarizing new sources and logic changes.
- Build a contributor guide for adding new feed adapters.

## Phase 4: Productization

- Add a weekly digest view.
- Add RSS output for the generated reports.
- Add shareable project cards for social distribution.
- Add optional English summaries for wider GitHub discovery.
